Design decisions are recorded as architecture decision records in
[`adrs/`](https://github.com/polylint/skif/blob/main/adrs/index.md). Read them before proposing a change in
direction.

## Crates

| Crate | Role |
| --- | --- |
| `skif-cli` | The command line: argument parsing, exit codes, install step after fixes. |
| `skif` | Embeddable facade: discover a workspace, lint it and plan fixes without IO side effects. |
| `skif-config` | `skif.toml` model, loading, CLI overrides and the JSON Schema. |
| `skif-core` | Diagnostic, fix, report and filesystem types shared by the other crates. |
| `skif-workspace` | Workspace discovery for npm, pnpm, yarn and bun: packages, manifests and catalogs. |
| `skif-lint` | Rule engine: rule registry, diagnostic emitter and parallel runner. |
| `skif-rules` | Built-in manifest, workspace, policy and catalog rules. |
| `skif-specifier` | npm dependency specifier parsing and comparison, vendored from syncpack. |
| `skif-edit` | Format-preserving JSON and YAML edits used by autofixes. |
| `skif-report` | Human, JSON, SARIF, GitHub, Code Climate, compact, Markdown and CODEOWNERS renderers. |
| `skif-js` | JavaScript and TypeScript module graph and dependency rules, built on oxc. |
| `skif-js-syntax` | oxc-based module facts and static config extraction; never executes code. |
| `skif-js-plugins` | `package.json` script parsing and the declarative plugin table. |
| `skif-js-types` | Type-aware facts from the TypeScript checker of tsrs: which member a read reaches. The only crate that depends on tsrs. |
| `skif-migrate` | The translation behind `skif migrate`: sherif, syncpack and knip configuration to `skif.toml`. |
| `skif-node` | The Node-API addon behind the npm package. |

## Key decisions

- [Mission, scope and non-goals](https://github.com/polylint/skif/blob/main/adrs/0001-mission-scope-and-non-goals.md): what skif is, what it never does, and its speed targets
- [Crates, library API and upstream code](https://github.com/polylint/skif/blob/main/adrs/0002-crates-library-api-and-upstream-code.md): layering, publishing, the pure-function contract and borrowed code
- [Configuration, suppressions, baselines and migration](https://github.com/polylint/skif/blob/main/adrs/0003-configuration-suppressions-baselines-and-migration.md): layered `skif.toml`, ignore reasons, baselines and `skif migrate`
- [Workspaces, roots and package managers](https://github.com/polylint/skif/blob/main/adrs/0004-workspaces-roots-and-package-managers.md): discovery, multi-root runs and per-manager semantics
- [Rules, diagnostics and fixes](https://github.com/polylint/skif/blob/main/adrs/0005-rules-diagnostics-and-fixes.md): stable rule ids, severities and format-preserving fixes
- [Version policies, lockfiles, toolchains and updates](https://github.com/polylint/skif/blob/main/adrs/0006-version-policies-lockfiles-toolchains-and-updates.md): syncpack-style policies, lockfile and toolchain rules, `skif update`
- [JS analysis core on oxc](https://github.com/polylint/skif/blob/main/adrs/0007-js-analysis-core-on-oxc.md): module graph, resolution, file discovery and the parse cache
- [Plugins, config evaluation and commands](https://github.com/polylint/skif/blob/main/adrs/0008-plugins-config-evaluation-and-commands.md): the declarative plugin table, static config evaluation and script parsing
- [What counts as a use](https://github.com/polylint/skif/blob/main/adrs/0009-what-counts-as-a-use.md): export, member, dependency and template usage
- [Type-aware analysis on tsrs](https://github.com/polylint/skif/blob/main/adrs/0010-type-aware-analysis-on-tsrs.md): opt-in typed member reads, their boundary and budget
- [Nx, Lerna and Bazel](https://github.com/polylint/skif/blob/main/adrs/0011-nx-lerna-and-bazel.md): projects, task layouts and Starlark read as text
- [CLI contract and reporting](https://github.com/polylint/skif/blob/main/adrs/0012-cli-contract-and-reporting.md): commands, flags, output formats, JSON contract and exit codes
- [Editors, agents and git hooks](https://github.com/polylint/skif/blob/main/adrs/0013-editors-agents-and-git-hooks.md): `skif lsp`, `skif mcp`, `--watch` and hook launchers
- [Benchmarks and the comparison harness](https://github.com/polylint/skif/blob/main/adrs/0014-benchmarks-and-the-comparison-harness.md): pinned corpus, parity with knip and syncpack, published numbers
- [Distribution, release and supported versions](https://github.com/polylint/skif/blob/main/adrs/0015-distribution-release-and-supported-versions.md): channels, release workflow and the support policy

The full list is the [ADR index](https://github.com/polylint/skif/blob/main/adrs/index.md).

## Pipeline

1. `skif-config` resolves defaults, then the `skif.toml` files from the root up to the ceiling (merged farthest
   first), then CLI overrides.
2. `skif-workspace` discovers packages and reports facts; it never decides that a fact is a problem. A run over
   several roots discovers each root and gives it its own configuration.
3. `skif-lint` builds a registry from the rule providers, validates every rule's options, and runs the providers
   concurrently. Rules emit diagnostics, optionally with fixes.
4. The JS analysis (`skif-js`, with `skif-js-syntax` and `skif-js-plugins`) is one of those providers. It parses the
   sources, builds the module graph, applies the plugin table and emits the `js` rules. With type-aware analysis on,
   `skif-js-types` builds one TypeScript program per `tsconfig.json` that holds a judged file, starting while the
   graph is built, answers which members the typed reads reach, and frees every program before the rules run.
5. `skif-edit` turns fixes into a `FixPlan` of format-preserving edits; the CLI writes the plan.
6. `skif-report` renders the report as human, JSON, SARIF, GitHub, Code Climate, compact, Markdown or CODEOWNERS output.
