skif is part of [polylint](https://github.com/polylint), a set of Rust linters and formatters for codebases that
agents work in. Each tool is a single binary with its own release, documentation and install channels.

| Tool | What it does |
| --- | --- |
| [skif](https://github.com/polylint/skif) | Dependency and package-manager linter for JavaScript and TypeScript, with first-class monorepo support. |
| [polylint](https://github.com/polylint/polylint) | One linter and formatter for every language in a repository (`poly`). It can run skif as an engine ([library usage](/skif/guides/library/)). |
| [adrlint](https://github.com/polylint/adrlint) | Linter and formatter for MADR architecture decision records. |
| [uncomment](https://github.com/polylint/uncomment) | Comment removal and linting. |

## Installing

skif installs from the organization's Homebrew tap and Scoop bucket, which also carry its sibling tools:

```sh
brew install polylint/tap/skif
```

```powershell
scoop bucket add polylint https://github.com/polylint/scoop-bucket
scoop install skif
```

skif's other channels (npm, crates.io, release archives, the GitHub Action and git hooks) are listed under
[Installation](/skif/start/installation/).
